- dc_bg_glass_card   feature/list card, gradient top->bottom, r16 (Figma "Button - Photo Cast")
- dc_bg_chip         pill chip / small pill button, r999 (Figma "More options dropdown pill")
- dc_bg_icon_tile    cyan icon tile behind feature icons, r12 (Figma "Background+Border+Shadow"); other hues = per-screen copy
- dc_bg_cta_gradient primary CTA with ripple, cyan -> blue -> indigo, r16 (Figma PRO "Button")
- dc_bg_key          remote key / round-rect icon button with ripple, r16 (Figma "Button - Back", header back)
- dc_bg_dialog       center modal card, r32 (Figma "The Modal Card")
- dc_bg_sheet        bottom sheet, top corners r36 (Figma "Main - NotificationBottomSheet")

Shared header: layout/item_header.xml (bound by BaseActivity.bindHeader) — back button on dc_bg_key tinted white,
title DC.Text.Heading. IDs unchanged.

Theme
- Theme.CastTV = Theme.AppCompat.NoActionBar (dark): windowBackground/statusBar/navigationBar dc_bg, colorAccent dc_primary,
  textColorPrimary white. BaseActivity sets status bar dc_bg with light icons. Theme.Splash uses @drawable/bg_splash.
